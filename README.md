# About AniMap
**AniMap** is a web application designed to help users easily find information about anime. On this website, users can search for anime based on specific criteria such as title, genre, rating, and more. After finding an anime they are interested in, users can bookmark it to categorize it however they like based on. One of AniMap’s main advantages is its Content-Based Filtering recommendation feature, which provides personalized anime suggestions based on each user’s preferences.


## How Does It Work
The **Content-Based Filtering** method in this system applies **Rule-Based Filtering**, where recommendations are generated using predefined rules based on an anime’s **title** and **genre**. The system first retrieves the user’s latest search history to extract relevant filters, then checks the bookmarked anime list and groups titles marked as *liked*, *plan to watch*, or *currently watching*. All gathered titles and genres are then used to query the [**Jikan API**](https://docs.api.jikan.moe/) for matching anime. The combined results are presented on the recommendation page, ensuring suggestions are relevant to the user’s interests.


## Key Features
1. Search animes with filters based on their properties (such as title, genre, rating, themes, etc).
2. Detailed information for each animes with additional informations like voice actors, production staffs, theme songs, and PVs.
3. Bookmark animes based on their status (liked, plan to watch, currently watching, disliked, and won't watch).
4. Automatic anime recommendations based on the users' anime list and recent activities.


## Limitations
For now, the page hasn't fully support mobile viewing yet, so desktop viewing is highly advisable.
